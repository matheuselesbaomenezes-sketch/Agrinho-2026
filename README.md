# Agrinho-2026
A pagina de uma internet
Objetivo da Página
O objetivo principal desta Landing Page é conscientizar e educar a comunidade escolar e os produtores locais sobre a importância de alinhar a alta produtividade no campo com práticas que protejam a natureza.

Ela foi desenhada para o tema "Agro forte, futuro sustentável", mostrando que a tecnologia e o respeito ao meio ambiente não são inimigos, mas sim parceiros para o futuro do agronegócio no Paraná.

Como Funciona (A estrutura técnica)
O site funciona combinando duas linguagens de programação Web fundamentais que você aprendeu no Alura Start:

HTML (A Estrutura e o Conteúdo):

Ele usa tags semânticas (como <header>, <main>, <section>, e <article>). Isso diz ao navegador exatamente o que cada parte do site significa, melhorando a acessibilidade (fundamental para critérios de correção).

O menu de navegação usa links internos (href="#sustentabilidade"). Quando o usuário clica, a página desliza automaticamente para aquela seção, sem precisar recarregar.

CSS (O Design e a Experiência do Usuário):

Layout Responsivo (Flexbox): Foi utilizado o sistema display: flex. Isso significa que se você abrir o site em um computador, os cards com as dicas ficam lado a lado. Se abrir em um celular, eles se organizam sozinhos um embaixo do outro, se ajustando perfeitamente à tela.

Identidade Visual: As cores foram planejadas usando variáveis (:root) com tons de verde e elementos visuais que remetem à natureza e à terra.

Interatividade (:hover): Quando o usuário passa o mouse por cima de um dos cards de dicas, o CSS aplica um efeito visual de "flutuar" (transform: translateY). Isso deixa o site mais dinâmico e interessante para quem está navegando.
